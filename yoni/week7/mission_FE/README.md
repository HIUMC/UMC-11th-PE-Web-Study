# Week 7

## FE

### 주제

인증과 인가의 이해 및 회원가입 API 연동

### 구현 내용

- 회원가입 화면 및 입력 폼 구현
- 이메일 형식, 닉네임 길이, 비밀번호 조건 및 비밀번호 일치 여부 검증
- 입력 조건에 따른 오류 문구 및 가입하기 버튼 상태 처리
- 이메일과 닉네임 중복 확인 API 연동
- 입력값 변경 시 해당 중복 확인 결과 초기화
- 중복 확인 요청 중 입력창과 버튼 비활성화
- 회원가입 API 연동 및 요청 진행, 성공, 실패 상태 처리

### 학습 내용

- 인증과 인가의 차이
- JWT의 header, payload, signature 역할
- JWT 디코딩과 서명 검증의 차이
- useState를 활용한 입력값 및 API 요청 상태 관리
- 환경 변수를 활용한 백엔드 API 주소 설정
- 클라이언트 유효성 검사와 서버 중복 확인의 차이

### 트러블 슈팅

- 이메일 중복 확인 요청 시 실패 알림 발생
- 백엔드 실행 포트는 3000이지만 API 주소는 8080으로 설정된 것이 원인
- API 주소를 수정하고 프론트엔드 개발 서버를 재시작하여 설정 적용
