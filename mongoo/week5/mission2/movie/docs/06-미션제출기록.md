# 백엔드 5주차 미션 — 영화 평점 서비스

> 구현과 설명은 준비되어 있다. 아래 [직접 첨부]/[직접 작성] 부분은 본인의 실제 실행 결과로 채운 뒤 제출한다. 체크박스는 확인 후 표시한다.

## 1. 목표와 구현 범위

Spring Boot로 닉네임 중복 체크, 이메일 중복 체크, 회원별 평점 조회 API를 구현하고 실제 브라우저 화면에서 호출한다. DB는 MySQL의 umc_movie_week5를 사용한다. 영화 상세 정보는 외부 TMDB가 관리하므로 우리 DB에는 movie_id만 저장한다.

## 7. 트러블슈팅

### SQL 실행 범위 혼동

- 이슈: 테이블 생성문 재실행으로 member already exists 오류가 발생했고, 여러 INSERT 중 일부만 실행됐는지 확인하기 어려웠다.
- 원인/진단: 현재 문장 실행과 전체/선택 실행을 구별해야 했다. Result #1은 행 수가 아니라 결과 탭 번호였다. SELECT DATABASE() 결과 NULL로 현재 선택 DB도 없음을 확인했다.
- 해결 과정: 새 DB umc_movie_week5에서 SQL을 한 문장씩 실행하고 테이블 목록을 확인했다. 이후 SQL에는 DB 이름을 명시해 선택 DB에 의존하지 않도록 했다.
