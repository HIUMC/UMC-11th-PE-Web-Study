# 04. 코드를 읽는 순서

## 요청이 처리되는 흐름

```text
브라우저 폼 → fetch → Controller → Service → Repository → MySQL
브라우저 표시 ← JSON ← Response DTO ← Service의 Entity → DTO 변환
```

1. `entity/BaseTimeEntity.java`: createdAt/updatedAt을 상속한다. @MappedSuperclass는 컬럼 정의만 물려주며 자체 테이블은 없다. @CreationTimestamp는 생성, @UpdateTimestamp는 Hibernate 저장 시 수정 시각을 관리한다.
2. `entity/Member.java`: 회원 테이블 매핑이다. @Id는 기본키, IDENTITY는 DB AUTO_INCREMENT를 사용한다. @Getter로 필드 getter를 만들고, JPA용 기본 생성자는 protected로 둔다.
3. `entity/Rating.java`: @ManyToOne은 여러 평점이 회원 하나를 참조함을 나타낸다. @JoinColumn은 실제 FK 컬럼 이름이다. LAZY는 연관 회원을 필요할 때 로드한다. movieId는 관계가 아닌 숫자 필드다.
4. `repository/MemberRepository.java`: JpaRepository<Member, Long>으로 기본 CRUD를 받고 existsByEmail/existsByNickname 이름에서 조회 조건을 만든다.
5. `repository/RatingRepository.java`: findByMember_MemberIdOrderByRatingIdDesc는 member.memberId로 필터하고 ratingId 내림차순 정렬한다. 언더스코어는 관계 탐색 경계를 명시한다.
6. `dto/`: record는 응답 데이터를 간결하게 표현한다. Entity를 그대로 응답하지 않아 password/연관 회원 객체가 노출되지 않는다. RatingResponse.from이 변환을 담당한다.
7. `service/MemberService.java`: exists를 반전해 available로 반환한다. 존재 여부와 사용 가능 여부는 반대다.
8. `service/RatingService.java`: 회원 존재 여부를 먼저 확인해 없는 회원 404와 평점이 없는 회원 []를 구별한다. 읽기 전용 트랜잭션 안에서 목록을 DTO로 변환한다.
9. `controller/`: @RestController는 반환 객체를 JSON 응답으로 변환한다. @PathVariable로 URL 값을 받는다. Controller는 경로를, Service는 처리 규칙을 담당한다. @RequiredArgsConstructor가 final 의존성을 받는 생성자를 만든다.
10. `config/WebConfig.java`: WebMvcConfigurer의 addCorsMappings에서 브라우저에 허용할 Origin과 경로를 설정한다. 설정 전 실험을 위해 환경 변수 스위치를 제공한다.
11. 기존 프론트 `week5/mission1/umcine/src/api/backend-client.ts`: TMDB 인스턴스와 별도로 Spring API 인스턴스를 만든다. TMDB 토큰을 백엔드에 보내지 않는다.
12. 기존 프론트 `src/api/members/get-member-data.ts`: 닉네임/이메일 Path 값을 인코딩하고 API 3개를 호출한다.
13. 기존 상세의 `src/components/movies/member-rating-panel.tsx`: 원래 내 평점 영역을 유지하면서 접이식 회원 확인 항목에서 실제 API를 호출한다. 평점 목록은 서버 정렬 그대로 표시하고, 현재 영화의 평점을 찾아 기존 별점/후기에 표시한다. 404/네트워크 오류/빈 목록을 구분한다. 새 라우트나 별도 사이트는 추가하지 않았다.
14. `../mock-frontend/index.html`: 워크북 실습 0/9절을 위한 fetch 버튼 하나의 간이 HTML이다. CORS 관찰용이며 최종 필수 미션은 기존 UMCine에서 진행한다.

## 실습 범위

회원가입/로그인/평점 쓰기/즐겨찾기 API는 이번 주 구현하지 않는다. H2는 자동 테스트에서만 사용한다. Spring Security도 추가하지 않았다. 선택 과제인 서버 입력 유효성 검증과 페이지네이션은 필수 API 응답을 바꾸지 않기 위해 포함하지 않았다.
