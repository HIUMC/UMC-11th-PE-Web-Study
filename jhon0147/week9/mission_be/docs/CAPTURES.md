기존 Swagger 분할 캡처에 평점·내 정보·즐겨찾기 조회/해제의 한 줄 설명과 인증 여부가 담겼다면 추가로 다시 찍지 않는다. 등록 문서는 상단 핵심 내용 한 장이면 된다. 실제 201·409 응답은 별도 캡처로 확인한다.

실패 메시지 설명: 단위 테스트는 기대한 ApiException 대신 NPE가 발생해 실패했고, 통합 테스트는 중복 요청에서 save가 호출돼 NeverWantedButInvoked로 실패했다. 원래 코드로 복원한 뒤 전체 70개가 다시 통과했다.

이번 로컬 실습의 기존 원본 캡처를 그대로 사용한다. 응답 캡처는 Request URL과 Server response 영역을 중심으로 남긴다. 트랜잭션 실험 순서는 REGRESSION.md를 따른다. 스터디 인증 사진은 별도 첨부한다.

선택 미션의 실제 설명: @Transactional을 제거하자 즐겨찾기 저장이 실패해도 평점 1개가 남았고, expected: 0L / but was: 1L로 테스트가 실패했다. @Transactional을 복원한 뒤 전체 70개가 다시 통과했다.

## 실제 파일 검토와 첨부 완료

바탕화면 9주차 캡처 폴더의 원본 JPG 12장을 검토하고 그대로 사용했다. Swagger목록1~3 분할 사진에 필수 API의 설명과 인증 구분이 모두 담겨 있다. 노션에 실제 이미지 12개가 저장된 것을 확인했으며 문서·201/409·중복 검사 실험·선택 트랜잭션 실험의 네 토글로 배치했다.

파일 전송 결과 12개 모두 uploaded 상태였고, 저장된 페이지에서 고유한 이미지 참조 12개를 확인했다. 추가 재캡처나 수동 사진 업로드는 필요하지 않다.
